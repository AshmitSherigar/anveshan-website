# Contributing

Thanks for contributing to Anveshan.

## Workflow

1. Create a branch from the latest main branch.
2. Make a focused change that matches the existing project structure.
3. Run the frontend checks from `frontend`:

   ```bash
   npm run lint
   npm run build
   ```

4. Open a pull request with a clear summary and testing notes.

## Pull requests

- Keep changes small and explain the reason for the change.
- Include screenshots for visible UI changes when useful.
- Update relevant documentation when behavior or workflow changes.
- Do not commit secrets, generated build output, or dependency folders.
