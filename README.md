# Anveshan

Anveshan is organized as a frontend application in the `frontend` folder.

## Getting started

1. Read the [frontend guide](frontend/README.md).
2. Install dependencies with `npm install` inside `frontend`.
3. Start the development server with `npm run dev` inside `frontend`.

## Contributing

Create a focused branch, make the smallest useful change, and run `npm run lint` and `npm run build` in `frontend` before opening a pull request. See [CONTRIBUTION.md](CONTRIBUTION.md) for the full contribution checklist.
